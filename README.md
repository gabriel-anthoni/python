Python é uma linguagem de programação simples e muito usada para back-end, criação de sites, automação, análise de dados e inteligência artificial. É conhecida por ser fácil de aprender e bastante versátil.

```python
print("Hello, World!")
```

<br>

## 🌟 Características do Python

<br>

<table>
  <tr>
    <td>
      <h3>📗 Sintaxe Simples e Legível</h3>
      <p>A sintaxe é o conjunto de regras que define como o código deve ser escrito em uma linguagem de programação. A sintaxe do Python é projetada para ser o mais limpa e legível possível, assemelhando-se ao inglês fluente.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🚀 Linguagem de Alto Nível</h3>
      <p>Afasta o programador das complexidades do hardware (como gerenciamento de memória, bits ou registros do processador), permitindo focar puramente na lógica do problema.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🔄 Interpretada</h3>
      <p>O código-fonte não é compilado diretamente para a linguagem de máquina. O Python primeiro compila o código para um formato intermediário chamado <i>bytecode</i>, e então a Máquina Virtual do Python (PVM) o interpreta e executa linha por linha.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🌍 Multiplataforma</h3>
      <p>O mesmo código roda em Windows, macOS, Linux ou sistemas embarcados sem precisar de modificações estruturais. O lema é: <i>"escreva uma vez, rode em qualquer lugar"</i>.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🎭 Multiparadigma</h3>
      <p>O Python oferece total liberdade e flexibilidade para o desenvolvedor escolher o melhor estilo de programação adequado para o projeto.<br><b>Suporta:</b></p>
      <ul>
        <li>Programação Estruturada</li>
        <li>Orientação a Objetos (POO)</li>
        <li>Programação Funcional</li>
      </ul>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🧬 Tipagem Dinâmica</h3>
      <p>O Python utiliza tipagem dinâmica, o que significa que o tipo de uma variável é determinado automaticamente em tempo de execução, sem a necessidade de declaração prévia.</p>
      <pre><code class="language-python">idade = 10    # O Python reconhece automaticamente como inteiro (int)
idade = "10"  # O tipo é atualizado para texto (str) de forma dinâmica</code></pre>
      <p>Essa flexibilidade permite reatribuir diferentes tipos de dados à mesma variável ao longo do seu código de maneira simples e segura.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🛡️ Tipagem Forte</h3>
      <p>O Python proíbe operações entre tipos incompatíveis (como tentar somar texto com número). Ele não faz conversões implícitas que possam gerar bugs silenciosos, exigindo conversões explícitas.</p>
      <pre><code class="language-python">10 + "10"  # Erro de tipo (TypeError)</code></pre>
      <p>Nesse exemplo, tentar somar um valor inteiro (<code>int</code>) e um texto (<code>str</code>) irá gerar um erro durante a execução do programa.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🔓 Código Aberto</h3>
      <p>No Python, código aberto (<i>open source</i>) significa que qualquer pessoa pode ver o código-fonte, estudar, modificar, melhorar e compartilhar a linguagem. Isso ajuda o Python a evoluir rapidamente com a colaboração de uma comunidade global.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>🔋 Baterias Inclusas</h3>
      <p>O termo <i>batteries included</i> significa que a linguagem já possui uma biblioteca padrão rica, com muitas ferramentas prontas para uso logo após a instalação (como manipulação de arquivos, funções matemáticas e recursos de rede), sem que você precise instalar pacotes externos para tarefas básicas.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>👥 Comunidade Gigante</h3>
      <p>Por sua facilidade de uso e por ser frequentemente a primeira linguagem de programação de muitos desenvolvedores, o Python possui uma comunidade imensa. Isso garante um vasto ecossistema de tutoriais, fóruns, bibliotecas e pessoas dispostas a colaborar.</p>
    </td>
  </tr>
</table>

## ⏳ Cronologia do Python

<br>

<table>
  <tr>
    <td>
      <h3>1989: A Origem</h3>
      <img src="https://upload.wikimedia.org/wikipedia/commons/6/6b/Guido_van_Rossum_in_PyConUS24_%28cropped%29.jpg" width="180" align="left">
      <p>Em dezembro de 1989, o programador holandês <b>Guido van Rossum</b>, que trabalhava no centro de pesquisa Centrum Wiskunde & Informatica (CWI) na Holanda, decidiu criar uma nova linguagem. Ele queria um projeto pessoal para se ocupar durante a semana do Natal, pois seu escritório estaria fechado.</p>
      <p><b>A Inspiração:</b> Guido queria uma linguagem que fosse sucessora espiritual da linguagem ABC (que ele ajudou a projetar, mas que apresentava limitações significativas de extensibilidade e sintaxe).</p>
      <p><b>O Nome:</b> O nome "Python" não tem relação com a cobra, mas foi inspirado no grupo de comédia britânico <i>Monty Python</i>, do qual Guido era um grande fã e admirador.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>1991: Primeira Versão Pública</h3>
      <p>Guido publicou oficialmente o código-fonte inicial do Python (versão <code>0.9.0</code>) no tradicional grupo de discussão <code>alt.sources</code> da Usenet. Esse marco histórico representou o nascimento público do projeto, permitindo que os primeiros desenvolvedores externos começassem a testar e contribuir com ideias.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>1994: Python 1.0</h3>
      <p>Após anos de contínuo aprimoramento e feedback da comunidade em expansão, é lançada a primeira versão oficial e estável da linguagem, o <b>Python 1.0</b>. Essa versão trouxe recursos fundamentais e ferramentas estruturadas que consolidaram as bases para o desenvolvimento de softwares robustos.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>1995: Mudança para o CNRI</h3>
      <p>Buscando ampliar o impacto do projeto, Guido mudou-se para os Estados Unidos para trabalhar no CNRI (<i>Corporation for National Research Initiatives</i>). Nesse período, ele continuou liderando o desenvolvimento do Python, refinando a biblioteca padrão e fortalecendo a adoção corporativa da linguagem.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>Maio de 2000: BeOpen PythonLabs</h3>
      <p>Guido e os principais desenvolvedores do núcleo deixam o CNRI e são contratados pela empresa <i>BeOpen.com</i>. Juntos, eles formam a equipe especializada <i>BeOpen PythonLabs</i> para trabalhar no avanço da linguagem em tempo integral, garantindo que o projeto continuasse totalmente aberto e gratuito.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>Setembro de 2000: Fim da Era 1.x</h3>
      <p>A última versão da geração Python 1.x é oficialmente lançada, encerrando um ciclo tecnológico importantíssimo que estabeleceu as raízes da linguagem e preparando o terreno para a chegada de uma arquitetura ainda mais moderna e eficiente.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>Outubro de 2000: Python 2.0</h3>
      <p>É lançado o marco histórico do <b>Python 2.0</b>, introduzindo inovações fundamentais para a computação moderna, como o sistema de coleta de lixo automatizada baseada em ciclos (para melhor gestão de memória) e o suporte abrangente a caracteres Unicode.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>2001: Fundação da PSF</h3>
      <div align="center">
        <img src="https://www.python.org/static/img/psf-logo.png" width="300">
      </div>
      <p>Após o encerramento das atividades do BeOpen PythonLabs, a <b>Python Software Foundation (PSF)</b> é oficialmente criada. Trata-se de uma organização sem fins lucrativos que assumiu definitivamente a propriedade intelectual, as marcas registradas e a governança do Python, assegurando que a linguagem permaneça livre, acessível e descentralizada para todo o planeta.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>2008: Python 3.0</h3>
      <p>Ocorre o lançamento do tão aguardado <b>Python 3.0</b> (frequentemente chamado de <i>Py3K</i>), uma atualização maior e ambiciosa projetada do zero para corrigir falhas estruturais de design herdadas do projeto original. Para alcançar essa evolução limpa, a equipe tomou a decisão consciente de quebrar a retrocompatibilidade com as versões anteriores.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>2020: Fim do Python 2</h3>
      <p>O Python 2 alcança oficialmente o seu fim da vida útil (<i>End of Life</i>) em 1º de janeiro, encerrando seu ciclo de suporte após anos de transição. Com isso, o Python 3 consolida-se de maneira absoluta e definitiva no mercado global de tecnologia, impulsionado pela explosão de sua adoção em Ciência de Dados, Engenharia de Software e Inteligência Artificial.</p>
    </td>
  </tr>
</table>

<table>
  <tr>
    <td>
      <h3>(Presente): A Era da Inteligência Artificial</h3>
      <p>Atualmente, o Python se consolida de forma incontestável como uma das linguagens de programação mais populares, influentes e amadas do mundo, liderando com folga o ecossistema de Inteligência Artificial, Machine Learning, automação de processos e desenvolvimento back-end corporativo.</p>
    </td>
  </tr>
</table>

### 📌 3. Testar se o Python foi instalado corretamente

Abra o seu terminal de preferência (**CMD / PowerShell** no Windows ou o **Terminal** no macOS/Linux) e digite o comando correspondente ao seu sistema operacional:

| Sistema Operacional | Comando no Terminal |
| :--- | :--- |
| <div align="center"><img src="https://skillicons.dev/icons?i=windows" width="40" /><br><b>Windows</b></div> | <pre><code>python --version</code></pre> |
| <div align="center"><img src="https://skillicons.dev/icons?i=apple,linux" width="80" /><br><b>macOS / Linux</b></div> | <pre><code>python3 --version</code></pre> |

Se o terminal retornar a versão instalada

**por exemplo:**

```
Python 3.14.7
```

significa que o interpretador está configurado corretamente e pronto para o uso! 🎉
